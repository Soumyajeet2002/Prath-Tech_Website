# PrathTech Chatbot — PHP

This repository contains a complete PrathTech chatbot implementation in PHP.

## Project Structure

```
prathtech/
├── index.php          ← Home page
├── css/
│   └── style.css      ← All styles
├── js/
│   └── chatbot.js     ← Full chatbot logic
└── README.md
```

## Setup

### Configuration

**PHP environment variable**

```
Add this in .env file: PRATHTECH_API_URL=https://your-backend.com
After that add the frontend url in backend .env file.
```

### Running Locally

```bash
cd prathtech
php -S localhost:8080
```
